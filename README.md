# EchoFit (UI-first)
This is the UI-only phase for EchoFit built with Expo + Expo Router. No backend yet.
- Run locally after cloning: npm install, then npx expo start
- Screens: Home, Workouts, Foods, Coach, Profile + Auth/Onboarding/WorkoutPlayer/Daily-Log/Paywall
- All flows use in-memory mock state; we’ll add Firebase/Functions in Phase 2.
